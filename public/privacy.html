폭풍의 잔향 (The Lost Storm 비공식 한국어 팬 번역), GitHub Pages에서 제공. 최종 갱신 2026년 11월 20일.

이 페이지가 설명하는 것

폭풍의 잔향은 The Lost Storm의 비공식 한국어 팬 번역으로, GitHub Pages에 올라간 정적 페이지다. 자체 서버나 계정 시스템이 없으므로, 플레이 데이터는 모두 그대의 브라우저 안에만 저장된다.

브라우저에 저장되는 것

  • 캐릭터와 진행 상황 (이 브라우저의 로컬 저장소)
  • 조작·음량 같은 설정

이 데이터는 어디로도 전송되지 않는다. 지우려면 브라우저의 사이트 데이터를 지우면 된다.

원작 게임

원작 The Lost Storm(theloststorm.com)에는 계정과 클라우드 저장이 있다. 그것은 원작의 정책이 적용되는 별개 서비스다. 원작의 개인정보 안내는 원작 사이트를 참고하라.
