# Security

If you find a security problem in the game, the site or this code, such as a way into someone else's account or save, a token that reaches the wrong address, or a page that runs injected script, please report it privately and not in a public issue, pull request or the Discord.

Once private vulnerability reporting is switched on for this repository, use it (Security tab, Report a vulnerability): that is the preferred channel. Until then, write to [contact@mergestorm.ai](mailto:contact@mergestorm.ai) with what you found, the steps to reproduce it, and what it lets someone do. You will get an answer, and we will tell you when it is fixed.

Please do not test against other players' accounts, run automated scans or load tests against theloststorm.com, or keep data you reach by accident.

Only the latest version of the game, the one live at [theloststorm.com](https://theloststorm.com), is supported.
